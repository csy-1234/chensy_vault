
 一、请求：method 会“影响是否有 body”（约定，不是绝对）

| Method | 是否通常有 request body | 说明        |
| ------ | ------------------ | --------- |
| GET    | ❌ 通常没有             | 语义是“获取资源” |
| POST   | ✅ 通常有              | 语义是“提交数据” |
| PUT    | ✅                  | 更新资源      |
| DELETE | 可有可无               | RFC 允许    |
