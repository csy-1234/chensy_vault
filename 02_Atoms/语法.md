##### 可变参数
	Variable Arguments，简称 `varargs`
Java 提供的一种功能，允许方法接受数量不定的参数。这意味着你可以在调用方法时传入任意数量的参数（包括 0 个）

**可变参数**的语法格式是：
	`type... parameterName`
	其中 `type` 是参数的类型，`parameterName` 是参数的名称


```java
public void printNumbers(int... numbers) {
    for (int num : numbers) {
        System.out.println(num);
    }
}
//表示可以传入任意数量的整数
```
