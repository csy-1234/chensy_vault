1.实体类相关注解
	@Entity @Table @Id @Column
来自

	spring-boot-starter-data-jpa

内部传递引入

	jakarta.persistence:jakarta.persistence-api   ← JPA 注解所在
	org.hibernate.orm:hibernate-core              ← 真正实现 ORM

2.Lombok 注解
	@Data @Getter @Setter
来自
```xml
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <scope>provided</scope>
</dependency>
```



3.Spring 相关注解
	@Controller @Service @Autowired
来自
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
```
内部关键 jar：

	org.springframework:spring-context    @Service
	org.springframework:spring-web 
	org.springframework:spring-webmvc   @Controller
	org.springframework:spring-beans      @Autowired


4.swagger注解

	@ApiModel 和 @ApiModelProperty
	swagger-annotations-1.6.10.jar

```xml
<dependency> 
	<groupId>io.swagger</groupId> 
	<artifactId>swagger-annotations</artifactId> 
	<version>1.6.10</version> <!-- 常见版本，也可能用 1.5.x 或 1.6.x --> 
</dependency>

<dependency> 
	<groupId>org.springdoc</groupId> 
	<artifactId>springdoc-openapi-ui</artifactId>
	<version>1.7.0</version> 
</dependency>
<!-- 新版本使用@Schema--> 

```





注解 → 属于某个 jar
jar → 属于某个框架
starter → 把一堆 jar 组合好
