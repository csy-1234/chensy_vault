使用步骤
1. 导入 SLF4J API（定义接口）
```xml
<!-- Maven 示例 --> 
<dependency> 
	<groupId>org.slf4j</groupId> 
	<artifactId>slf4j-api</artifactId> 
	<version>2.0.12</version> 
</dependency>
```

2. 导入一个 SLF4J 的绑定实现（提供具体实现类 + 配置机制）
```xml
<!-- Logback 示例 --> 
<dependency> 
	<groupId>ch.qos.logback</groupId> 
	<artifactId>logback-classic</artifactId> 
	<version>1.4.14</version> 
</dependency>
```

3. 编写日志代码 + 配置文件3

代码中使用 SLF4J 接口（面向接口编程）
```java
import org.slf4j.Logger; 
import org.slf4j.LoggerFactory; 
public class MyService { 
	private static final Logger log = LoggerFactory.getLogger(MyService.class); 
	public void doSomething() { log.info("操作成功"); // ← 调用的是接口方法 
	} 
}
```

通过实现框架的配置文件控制行为
```
如果用 Logback → 写 src/main/resources/logback.xml
如果用 Log4j2 → 写 log4j2.xml
配置内容包括：
日志级别（info/debug/warn...）
输出目标（控制台、文件、网络等）
日志格式（pattern）
滚动策略（按天、按大小分割）
```

这就是 SLF4J + 日志实现组合的优雅之处：编译期解耦，运行时灵活，配置驱动行为
