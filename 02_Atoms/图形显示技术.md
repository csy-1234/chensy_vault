**适配屏幕宽度、像素密度与触控交互**，技术上依赖 **viewport、响应式布局、相对单位、高分屏图片、触控优化**。

物理像素Physical Pixels
设备屏幕真正的点阵；硬件层面概念；CSS 并不会直接用它布局；

CSS 像素 (CSS Pixels)
浏览器用来做网页布局的单位；CSS 像素是虚拟的，用来统一网页布局的，而不是物理像素；实际写前端代码的px指的是css px；



```
example
在 CSS 里你写的：
	width: 100px;
   height: 50px;
100px/50px 指的就是 CSS 像素，这是浏览器用来做布局的“逻辑像素”，和物理像素无关。
浏览器会根据设备的 DPR 把 CSS 像素映射到物理像素上去显示：
物理像素 = CSS 像素 × DPR
```
