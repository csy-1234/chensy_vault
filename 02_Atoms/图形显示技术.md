物理像素Physical Pixels
设备屏幕真正的点阵；硬件能显示的最小单；单位px；CSS 并不会直接用它布局；分辨率=宽的物理像素*高上的物理像素，例如iPhone 12 物理像素是 1170 × 2532 px（分辨率只是数量，不是屏幕大小，像素密度PPI（Pixels Per Inch每英寸像素数）=   ；单位像素/英寸 (px/in)）

1. 先算对角线像素数：
对角线像素数=W2+H2\text{对角线像素数} = \sqrt{W^2 + H^2}对角线像素数=W2+H2​

2. PPI 公式：
    

PPI=对角线像素数屏幕对角线尺寸 D (inch)\text{PPI} = \frac{\text{对角线像素数}}{\text{屏幕对角线尺寸 D (inch)}} PPI=屏幕对角线尺寸 D (inch)对角线像素数​

CSS 像素 (CSS Pixels)
浏览器用来做网页布局的单位；CSS 像素是虚拟的，用来统一网页布局的，而不是物理像素；实际写前端代码的px指的是css px；


> [!Question] 问题
> 为什么直接用物理像素布局网页
> 设备差异太大（屏幕大小、分辨率）
> 直接用 **物理像素布局**，同一个网页在不同设备上会大小不一
> CSS 像素提供了 **统一的逻辑单位**，让布局和字体大小在各种设备上保持一致的视觉效果
> 高分屏上1csspx=多个物理像素（dpr>1）
> 



```
example
在 CSS 里你写的：
	width: 100px;
   height: 50px;
100px/50px 指的就是 CSS 像素，这是浏览器用来做布局的“逻辑像素”，和物理像素无关。
浏览器会根据设备的 DPR 把 CSS 像素映射到物理像素上去显示：
物理像素 = CSS 像素 × DPR
```

移动设备的两个屏幕宽度：
物理屏幕宽度：屏幕真正的像素点数，例如 iPhone 14：1170 px

CSS 宽度（viewport width）：iPhone 14 Safari 默认 375 CSS px
    
即 **浏览器布局使用 375px 宽度做参照**
        
- DPR = 物理像素 / CSS 像素 = 1170 / 375 = 3
    

✅ 所以你看到的网页布局宽度是 375px（CSS px），但是屏幕实际点阵有 1170 个像素（物理 px）
