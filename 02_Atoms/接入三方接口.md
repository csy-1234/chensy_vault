### 三方接口的意义
通用意义：
1.快速补齐能力
	减少重复劳动
实际应用：
- 💳 支付（微信 / 支付宝 / 银行）
    
- 🚚 物流（顺丰 / 菜鸟 / 快递 100）
    
- 📩 短信 / 邮件（阿里云 / 腾讯云）
    
- 🧠 AI / OCR / 语音识别
    
- 🧾 身份认证 / 风控 / 实名
    
👉 自己做 = 高成本 + 高风险 + 长周期

2.合规&风险转移
	减少资质负担
3.稳定性高、便宜
4.业务聚焦

### 通用接入步骤
1.需求 & 场景确认
	干什么用的
	哪些业务需要调用
	同步还是异步
2.申请接入、资质审核

3.阅读接口文档（非常重要）
重点看这 6 个点：

1. 接口地址（测试 / 正式）
    
2. 请求方式（GET / POST）
    
3. 参数说明
    
4. 签名规则
    
5. 返回结构
    
6. 错误码
    

📌 **一定先跑通 demo / 示例**
