### 是什么
> [!NOTE] 
语言，是一种用“符号 + 规则+符号语义”，  
在主体之间传递、存储和操作意义的系统。

### 语言四大属性
语言类型
	本体分类定位/第一性问题：是不是形式语言？是不是自然语言
表示方式
	线性文本（text）、图形（diagram）、符号（symbolic）、声音（speech）、手势（gesture）
理论属性：
	语言的理论上的复合某种理论
使用场景：
	使用用途和解释内容是什么

这里一个使用一般是表示方式+语言类型+组合

### 语言的确定


> [!NOTE] 
>语言是一套符号、规则及其语义解释机制。  
人们常把不同语言误认为同一种，  
是因为只从“使用场景”出发，  
而忽略了符号、语法、语义和解释器这几个本体维度。
> 

确定一个“语言”是否成立，只需要确定其中的 2 个半维度:
必须明确的
1. **语言类型（Type）—— 必须**
2. **核心语义规则（属于理论属性的一部分）—— 必须**
不必完全确定，但一定“隐含存在”的
3. **表示方式（Representation）—— 至少一种**
4. **使用场景（Purpose）—— 可以不唯一、可后置**

👉 **不是四选几，而是：  
Type + Semantic Rules 是“存在条件”，  
另外两个是“实现 / 使用条件”**

那“理论属性”为什么不是必须完整确定
理论属性不是“是否是语言”的条件，  
而是“这门语言能做到什么”的条件。
### 常见语言
语言
├── 自然语言（人类）
├── 形式语言（人造）
├── 符号语言
├── 表达语言（非线性）
├── 生物语言
├── 物理 / 数学语言
└── 机器 / 系统语言

自然语言（Natural Language）
汉语、英语、法语；方言；书面语 / 口语；
- 不完全可形式化；
- 高度依赖上下文；
- 模糊但高效；
- “人 ↔ 人”的语言

形式语言（Formal Language）
- 严格语法；无歧义；
- 可被机器完全解析；

符号语言（Symbolic Language）
- 不靠自然句子
- 但能精确表达结构和关系
- 很多工程师其实是在“读图语言”

表达语言（非线性语言）
- 它们不是一句一句排开的；
- 没有“语法错误”
- 但有“表达失败”
- 传递的不是“事实”，而是**感受 / 意图 / 氛围**
- 音乐、 绘画、建筑、电影剪辑、设计（UI/UX）

生物语言（Biological Language）
这是很多人没意识到的，但非常重要。
- DNA（四个碱基 + 规则 → 生命）
- 激素信号
- 细胞信号通路
- 动物行为信号（蜂舞）
📌 **DNA 是一种极其成功的语言**
- 符号：ATCG
- 规则：编码、转录、翻译
- 语义：蛋白质 / 性状

物理 / 数学语言
-  数学、物理公式、逻辑系统
- 极度抽象
- 跨文化
- 不依赖人类情感

机器 / 系统语言
- CPU 指令集
- 协议（HTTP / TCP）
- 状态机
- 信号灯系统
- 操作系统接口
### 语言分类

```
语言（主分类轴/第一性划分）
├── 自然语言（Non-formal Language）
└── 形式语言（Formal Language）
（是否形式化formality of senmantics/是否允许语义歧义 / 是否可被形式系统完全解释）

└── 形式语言（Formal Language）（子轴分类+条件轴（conditional axis））
	├──可执行形式语言
	└── 不可执行形式语言
（是否可执行（Executability））

	├──可执行形式语言（计算能力轴（Computational Power））
		├── 图灵完备
		└── 非图灵完备
(计算能力（Computational Power）)

并行分类/两条独立的分类线（表现层Representation Layer属性）（使用场景分类）
语言
├── 描述型
├── 查询型
├── 控制型
└── 推理型
表达目标（Purpose）分类
```

 可执行形式语言（Executable FL）
> 能直接驱动某种抽象机器产生状态变化

 eg：通用编程语言（Java / C）、受限编程语言（SQL / Bash）
子类：
	Java / Python → 图灵完备
	SQL / 正则（理论上） → 非图灵完备

 不可执行形式语言（Non-executable FL）
**定义**：
> 只能描述结构或事实，本身不定义执行过程

eg：数据描述语言（JSON / XML）、标记语言（Markdown）


### 语言的诞生


> [!NOTE] 
>**语言的诞生有两条完全不同的路径：**
**① 自然演化型语言：先有思考 → 再有表达 → 语言逐步稳定**  
**② 设计构造型语言：先定义规则 → 再承载思考与执行**

你提到的“四大属性”，在这两条路径里，**出现顺序是完全不一样的**
**①**自然演化型语言（先思考，后语言）
```
现实世界
   ↓
感知 / 行为 / 思考
   ↓
临时表达（手势 / 声音 / 符号）
   ↓
约定俗成
   ↓
语言逐步稳定

在这个过程中：
❌ 没有人“设计语言”
❌ 没有明确的分类
❌ 没有形式化的语法

只有一个目标：
“让别人懂我”


```
例如：自然语言

数学 / 物理语言：不是纯粹的设计构造型语言，是“发现 → 抽象 → 形式化”的语言，不是像 Java 那样先被完整设计出来的；所以既不是自然语言语言也不是设计型语言
物理不是纯形式语言，为物理包含：
- 经验假设
- 实验解释
- 模型适用范围
- 理想条件说明
这些 **无法完全形式化**。物理学 = 自然语言 + 数学形式语言

自然演化型语言需要语言诞生前确定四大属性

**② 设计构造型语言**
```
目标问题
   ↓
抽象模型
   ↓
设计符号 + 规则
   ↓
定义语义解释器
   ↓
使用语言进行表达 / 推理 / 执行

```
例如：编程语言
设计型语言：

|属性|是否在发明前就确定|
|---|---|
|语言类型|✅|
|表示方式|✅|
|理论属性|✅|
|使用场景|✅|

📌 不然语言无法落地  
📌 不然解释器无法实现


自然语言和设计语言的发展关系：
 成立的版本是：

> 当思想从“表达意义”转向“保证推理正确性”时，  
> 语言必然从自然语言  
> 走向形式语言。

不成立的版本是：

> 一切语言都会自然进化成形式语言  
> ❌（错误）

因为：

- 文学
- 哲学
- 情感表达
**并不以消除歧义为目标**


> [!note]
> 语言并非总是先被设计好再使用。  
> 自然语言从思考中生长，  
> 设计语言反过来塑造思考。  
> 四大属性，  
> 对前者是总结结果，  
> 对后者是设计前提



### 总结

> [!ERROR] 总结 
> **语言不是声音、文字、代码、符号本身，  而是：  一种让“内部状态”在不同主体之间复制的机制**
