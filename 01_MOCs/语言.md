### 是什么
语言，是一种用“符号 + 规则”，  
在主体之间传递、存储和操作意义的系统。

### 语言的三个不可缺条件
（不是都满足就不是语言）
1.符号（Symbol）
字/音/颜色/数字/波形/分子结构
2.规则（Grammar / Syntax）
符号组合方式、顺序、约束
3.语义（Meaning）
这些符号“指代什么”
### 常见语言
语言
├── 自然语言（人类）
├── 形式语言（人造）
├── 符号语言
├── 表达语言（非线性）
├── 生物语言
├── 物理 / 数学语言
└── 机器 / 系统语言

自然语言（Natural Language）
汉语、英语、法语；方言；书面语 / 口语；
- 不完全可形式化；
- 高度依赖上下文；
- 模糊但高效；
- “人 ↔ 人”的语言

形式语言（Formal Language）
- 严格语法；无歧义；
- 可被机器完全解析；

符号语言（Symbolic Language）
- 不靠自然句子
- 但能精确表达结构和关系
- 很多工程师其实是在“读图语言”

表达语言（非线性语言）
- 它们不是一句一句排开的；
- 没有“语法错误”
- 但有“表达失败”
- 传递的不是“事实”，而是**感受 / 意图 / 氛围**
- 音乐、 绘画、建筑、电影剪辑、设计（UI/UX）

生物语言（Biological Language）
这是很多人没意识到的，但非常重要。
- DNA（四个碱基 + 规则 → 生命）
- 激素信号
- 细胞信号通路
- 动物行为信号（蜂舞）
📌 **DNA 是一种极其成功的语言**
- 符号：ATCG
- 规则：编码、转录、翻译
- 语义：蛋白质 / 性状

物理 / 数学语言
-  数学、物理公式、逻辑系统
- 极度抽象
- 跨文化
- 不依赖人类情感

机器 / 系统语言
- CPU 指令集
- 协议（HTTP / TCP）
- 状态机
- 信号灯系统
- 操作系统接口
### 语言分类
第一性划分

```
语言
├── 自然语言（Non-formal Language）
└── 形式语言（Formal Language）
（是否形式化formality of senmantics）

└── 形式语言（Formal Language）
	├──可执行形式语言
	└── 不可执行形式语言
（是否可执行（Executability））

	├──可执行形式语言
		├── 图灵完备
		└── 非图灵完备
(计算能力（Computational Power）)

```

 可执行形式语言（Executable FL）
> 能直接驱动某种抽象机器产生状态变化

 eg：通用编程语言（Java / C）、受限编程语言（SQL / Bash）
子类：
	Java / Python → 图灵完备
	SQL / 正则（理论上） → 非图灵完备

 不可执行形式语言（Non-executable FL）
**定义**：
> 只能描述结构或事实，本身不定义执行过程

eg：数据描述语言（JSON / XML）、标记语言（Markdown）




总结:
> **语言不是声音、文字、代码、符号本身，  
> 而是：  
> 一种让“内部状态”在不同主体之间复制的机制**
