### 是什么
> [!NOTE] 
语言，是一种用“符号 + 规则+符号语义”，  
在主体之间传递、存储和操作意义的系统。

### 3个集合
符号集（Symbol Set）
**定义**：语言的最小单位集合，用来构建表达。
必须的条件：
	可区分
	可被传递或表达；至少有一种可以被**记录或感知**的媒介；不必局限于文字，也可以是图形、声音、触觉信号（盲文、手语、触觉符号）

规则集（Grammar / Syntax）
**定义**：规定符号如何组合成合法表达的集合。
必须的条件：
	**组合规则**：明确哪些符号序列是合法的
	**可判定性**：对给定符号序列，能够判断其合法性（至少由人类可判定）
	**支持语义映射**
	表现形式：文字句法规则、图形组合规则、操作顺序规则
	稳定产生符号组合，形成可解释的结构
语义集（Semantic Mapping / Meaning Set）
**定义**：符号或符号组合对应的意义集合。
必须条件：
	每个合法符号组合都有意义
	**意义可被接收者理解**（自然语言）或可被系统解释（形式语言）
### 语言四大属性
语言类型
	本体分类定位/第一性问题：是不是形式语言？是不是自然语言
表示方式
	线性文本（text）、图形（diagram）、符号（symbolic）、声音（speech）、手势（gesture）
理论属性：
	语言的理论上的复合某种理论
使用场景：
	使用用途和解释内容是什么

这里一个使用一般是表示方式+语言类型+组合

### 语言的确定

确定1：
> [!NOTE] 
>语言是一套符号、规则及其语义解释机制。  
人们常把不同语言误认为同一种，  
是因为只从“使用场景”出发，  
而忽略了符号、语法、语义和解释器这几个本体维度。
> 

要确定一个语言：
必须有三个集合
**符号集 + 规则集 + 语义集**
- 没有符号集 → 不是语言
- 没有规则集 → 不稳定、无法交流 → 不是语言
- 没有语义 → 符号只是标记，不是语言

确定2：
每种语言都有**四个固定属性**：

1. **主分类轴 / 第一性划分** → 自然语言 / 形式语言
2. **使用场景 / 表现层分类** → 描述型、查询型、控制型、推理型、表达型等
3. **理论属性** → 可执行/不可执行、图灵完备/非图灵完备、符号化程度等
4. **表示方式属性 / 表征层** → 数据描述、符号系统、视觉/听觉表现、生物信号、协议/指令集等

| 语言   | 主分类    | 使用场景     | 理论属性      | 表示方式    |
| ---- | ------ | -------- | --------- | ------- |
| 汉语   | 自然语言   | 描述型 / 交流 | 不完全形式化    | 口语/书面文字 |
| JSON | 形式语言   | 描述型      | 不可执行      | 数据描述符号  |
| SQL  | 形式语言   | 查询型      | 可执行/非图灵完备 | 脚本/指令   |
| Java | 形式语言   | 控制型      | 可执行/图灵完备  | 编程语言符号  |
| 数学公式 | 形式语言   | 推理型      | 不可执行      | 符号语言    |
| 音乐   | 特殊/非标准 | 表达型      | 不可执行      | 声音/符号表示 |
| DNA  | 特殊/非标准 | 生物语言     | 不可执行      | 碱基序列    |

- **每个属性都有可穷举的值**（或至少是主要类别），组合后可以唯一确定语言。
- 特殊语言（音乐、DNA、蜂舞等）都可以用四属性表示，只要主分类强制选择特殊/非标准即可

> 核心思想：每种语言一旦诞生，这四个属性就固定了。**通过这四个属性组合，可以唯一确定该语言**
> 语言 = {主分类属性, 使用场景属性, 理论属性, 表示方式属性}，每种语言在这个四维空间里有唯一坐标。
### 语言的诞生路径


> [!NOTE] 
>**语言的诞生有两条完全不同的路径：**
**① 自然演化型语言：先有思考 → 再有表达 → 语言逐步稳定**  
**② 设计构造型语言：先定义规则 → 再承载思考与执行**

你提到的“四大属性”，在这两条路径里，**出现顺序是完全不一样的**
**①**自然演化型语言（先思考，后语言）
```
现实世界
   ↓
感知 / 行为 / 思考
   ↓
临时表达（手势 / 声音 / 符号）
   ↓
约定俗成
   ↓
语言逐步稳定

在这个过程中：
❌ 没有人“设计语言”
❌ 没有明确的分类
❌ 没有形式化的语法

只有一个目标：
“让别人懂我”


```
例如：自然语言



**② 设计构造型语言**
```
目标问题
   ↓
抽象模型
   ↓
设计符号 + 规则
   ↓
定义语义解释器
   ↓
使用语言进行表达 / 推理 / 执行

```
例如：编程语言
设计型语言：

|属性|是否在发明前就确定|
|---|---|
|语言类型|✅|
|表示方式|✅|
|理论属性|✅|
|使用场景|✅|

📌 不然语言无法落地  
📌 不然解释器无法实现

**3.混合语言**
数学 / 物理语言：不是纯粹的设计构造型语言，是“发现 → 抽象 → 形式化”的语言，不是像 Java 那样先被完整设计出来的；所以既不是自然语言语言也不是设计型语言
物理不是纯形式语言，为物理包含：
- 经验假设
- 实验解释
- 模型适用范围
- 理想条件说明
这些 **无法完全形式化**。物理学 = 自然语言 + 数学形式语言

 
 自然语言和设计语言的发展关系：
 成立的版本是：

> 当思想从“表达意义”转向“保证推理正确性”时，  
> 语言必然从自然语言  
> 走向形式语言。

不成立的版本是：

> 一切语言都会自然进化成形式语言  
> ❌（错误）

因为：

- 文学
- 哲学
- 情感表达
**并不以消除歧义为目标**

### 学习语言的路径

不管学哪种语言，路径几乎一模一样：

词汇 → 句子 → 段落 → 文章 → 风格 / 架构

语法 → 语句 → 函数 → 模块 → 系统设计
🟢 L1：语法层（初学者）写得慢
🟡L2：表达层（熟练者）模仿优秀表达
🔵L3：结构层（高手） 程序员 = 架构思维  、 写作者 = 结构思维
🔴 L4：思想层（专家）关注：传达什么思想

所有语言的终极目标，  
不是“说得对”，  
而是**让对方准确理解你想表达的世界模型**。
### 语言分类

```
语言（主分类轴/第一性划分）
├── 自然语言（Non-formal Language/Natural language）
└── 形式语言（Formal Language）
（是否形式化formality of senmantics/是否允许语义歧义 / 是否可被形式系统完全解释）

└── 形式语言（Formal Language）（子轴分类+条件轴（conditional axis））
	├──可执行形式语言
	└── 不可执行形式语言
（是否可执行（Executability））

	├──可执行形式语言（计算能力轴（Computational Power））
		├── 图灵完备
		└── 非图灵完备
(计算能力（Computational Power）)

并行分类/两条独立的分类线（表现层Representation Layer属性）（使用场景分类）
语言
├── 描述型 
├── 查询型
├── 控制型
├── 推理型
├── 表达型 → 音乐 / 绘画 / UI/UX设计
└── 生物语言
表达目标（Purpose）分类
```

 可执行形式语言（Executable FL）
> 能直接驱动某种抽象机器产生状态变化

 eg：通用编程语言（Java / C）、受限编程语言（SQL / Bash）
子类：
	Java / Python → 图灵完备
	SQL / 正则（理论上） → 非图灵完备

 不可执行形式语言（Non-executable FL）
**定义**：
> 只能描述结构或事实，本身不定义执行过程

eg：数据描述语言（JSON / XML）、标记语言（Markdown）

### 常见语言
语言
├── 自然语言（人类）
├── 形式语言（人造）
├── 符号语言
├── 表达语言（非线性）
├── 生物语言
├── 物理 / 数学语言
└── 机器 / 系统语言

自然语言（Natural Language）
汉语、英语、法语；方言；书面语 / 口语；
- 不完全可形式化；
- 高度依赖上下文；
- 模糊但高效；
- “人 ↔ 人”的语言

形式语言（Formal Language）
- 严格语法；无歧义；
- 可被机器完全解析；

符号语言（Symbolic Language）
- 不靠自然句子
- 但能精确表达结构和关系
- 很多工程师其实是在“读图语言”

表达语言（非线性语言）
- 它们不是一句一句排开的；
- 没有“语法错误”
- 但有“表达失败”
- 传递的不是“事实”，而是**感受 / 意图 / 氛围**
- 音乐、 绘画、建筑、电影剪辑、设计（UI/UX）

生物语言（Biological Language）
这是很多人没意识到的，但非常重要。
- DNA（四个碱基 + 规则 → 生命）
- 激素信号
- 细胞信号通路
- 动物行为信号（蜂舞）
📌 **DNA 是一种极其成功的语言**
- 符号：ATCG
- 规则：编码、转录、翻译
- 语义：蛋白质 / 性状

物理 / 数学语言
-  数学、物理公式、逻辑系统
- 极度抽象
- 跨文化
- 不依赖人类情感

机器 / 系统语言
- CPU 指令集
- 协议（HTTP / TCP）
- 状态机
- 信号灯系统
- 操作系统接口



> [!note]
> 语言并非总是先被设计好再使用。  
> 自然语言从思考中生长，  
> 设计语言反过来塑造思考。  
> 四大属性，  
> 对前者是总结结果，  
> 对后者是设计前提

### 常见误区


> [!error] 
> 出现在同一使用场景里的语言都是一个语言

"sql、正则、json是编程语言，我见到这些用在编程里，我以为是属于编程语言的一部分"

它们不是“通用编程语言”，  
但它们是“形式语言（Formal Language）”，  
并且通常被“嵌入”在编程语言中使用。

它们都不具备完整的“控制流 + 状态管理”能力  
👉 所以不独立承担“程序”这个角色


> [!error] 
>语言类型(主分类) 和 表示方式 混在一起
>

编程语言是文本语言
实际是：编程语言是形式语言





> [!note] 总结 
> **语言不是声音、文字、代码、符号本身，  而是：  一种让“内部状态”在不同主体之间复制的机制**
